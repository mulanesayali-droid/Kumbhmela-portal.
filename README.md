# KumbhMela Portal

A web-based platform designed to efficiently manage pilgrims, events, and resources during the Kumbh Mela using modern web technologies.

---

## 🛠 Tech Stack
- **Backend:** Python, Flask  
- **Database:** SQLite  
- **Frontend:** HTML, CSS, Bootstrap  
- **Visualization:** Charts & dashboards (Flask templates)

---

## 📌 Project Overview
The **KumbhMela Portal** is developed to support large-scale event management by digitizing pilgrim registration, event coordination, and resource monitoring.  
It provides administrators with real-time insights and organized data to ensure smooth operations during the Kumbh Mela.

---

## ✨ Key Features
- 🧑‍🤝‍🧑 **Pilgrim Registration & Management**
- 📅 **Event Scheduling and Tracking**
- 📊 **Data Visualization Dashboard**
- 🚨 **Real-time Monitoring of Resources**
- 🔐 **Secure Admin Panel**
- 🗂 **Centralized Database using SQLite**
